# 04 - Unsupervised Learning Clustering

## Objective

Cluster raw text documents into latent topic groups without labeled targets using a TF-IDF + K-Means pipeline.

## Files Included

| File                                          | Purpose                                                           |
| --------------------------------------------- | ----------------------------------------------------------------- |
| `04_Unsupervised_Learnining_Clustering.ipynb` | End-to-end unsupervised NLP workflow using Wikipedia article text |
| `README.md`                                   | Module documentation                                              |

## What Is Implemented

1. Fetch article text from Wikipedia API for three domains:
   - Astrophysics
   - Biology
   - Computer Science
2. Clean and normalize text
3. Lemmatize with NLTK WordNet lemmatizer
4. Vectorize with `TfidfVectorizer(max_features=1000)`
5. Train `KMeans(n_clusters=3, n_init=20)`
6. Evaluate with inertia (WCSS) and silhouette score
7. Predict cluster membership for unseen sample sentences
