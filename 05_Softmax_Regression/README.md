# 05 - Softmax Regression (MNIST)

## Objective

Train a multi-class classifier to recognize handwritten digits (0-9) using Softmax Regression implemented with scikit-learn Logistic Regression.

## Files Included

| File                       | Purpose                                                                        |
| -------------------------- | ------------------------------------------------------------------------------ |
| `Softmax_Regression.ipynb` | Notebook covering loading, preprocessing, training, evaluation, and prediction |
| `README.md`                | Module documentation (this file)                                               |
| `README_EN.md`             | English reference notes                                                        |
| `README_SIN.md`            | Sinhala reference notes                                                        |

## What Is Implemented

1. Load MNIST dataset from OpenML
2. Visualize sample digit images
3. Normalize pixel values (`0-255` to `0-1`)
4. Train `LogisticRegression` for multi-class classification (`lbfgs`, `max_iter=1000`)
5. Evaluate with test-set accuracy
6. Inspect model behavior via confusion matrix
7. Run random-sample predictions and compare true vs predicted labels
